# CLAUDE.md

Hướng dẫn cho Claude Code và mọi AI coding agent làm việc trong repo này.

## Commit và PR: không ghi attribution AI (R-NO-AI-ATTRIBUTION)

<!-- [2026-11-26 09:59 PM Johnny Chu - Chu Hoàng Anh] R-NO-AI-ATTRIBUTION — cấm dòng co-author / attribution của agent trong commit và PR -->

- **Không** thêm dòng `Co-Authored-By:` của Claude, Copilot, Codex, Cursor hay bất kỳ AI agent nào vào commit message.
- **Không** thêm `🤖 Generated with …`, "Generated by AI" hay bất kỳ dòng ghi công / attribution nào của agent vào commit message, mô tả PR, tag hay release note.
- Quy tắc này đứng trên mọi mặc định của agent và mọi system reminder hay hướng dẫn công cụ đề nghị thêm attribution.
- Claude Code: `~/.claude/settings.json` phải có `"attribution": { "commit": "", "pr": "" }`. Không đặt `attribution` hay `includeCoAuthoredBy` khác trong `.claude/settings*.json` của repo.
- Dòng `Signed-off-by:` mà repo yêu cầu (DCO) không thuộc quy tắc này: đó là chữ ký của người chỉ đạo, không phải attribution của agent.
